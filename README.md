**Termia**

Termia is a Vertical Scrolling Rhythm Game(VSRG) Client for the Terminal.

Current Support:
- Basic 4k osu!mania maps (extracted folders)

Feature Ideas / TODO:
- Support for variety of key combinations
- SV Change support
- Customization Options
- Config saving
- Terminal Argument support
- Better Timing Handling


How to use:
- Extract beatmap content into a folder
- Start Termia
- Configure Options
- Select Folder containing beatmaps (currently still hardcoded)
- Select chart
